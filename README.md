# 帛琉南島永續實踐計畫・學員行程網站

N-10-3 帛琉南島永續實踐計畫（青年百億海外圓夢基金・海外翱翔組）的行程網站，主要使用者是**錄取的學員**。

## 功能
- **每日行程**：點選 7/29–8/12 的日期，查看當天的主題、SDG 與景點；每個景點都有「在 Google Maps 開啟」按鈕
- **行前培訓**：7/14 培訓課程時間表
- **行前準備清單**：可勾選，也可以新增自己的項目，會顯示完成進度
- **每日預計消費試算（側欄）**：
  - ① 總預算平均法：總預算 ÷ 天數
  - ② 逐日分類法：依餐飲、交通、門票、紀念品、其他分別估算
  - USD ↔ TWD 匯率換算，並和記帳的實際支出比較
- **收支記帳**：記錄收入與支出，可選 USD 或 TWD，自動換算並計算結餘
- **心得筆記**：用「五感永續地圖」記錄每天的田野觀察，可下載成 .txt
- **使用注意**：帛琉宣言、防曬乳禁令、Bai 會所禮儀等
- **響應式設計**：桌機與手機都能正常使用，並支援 `prefers-reduced-motion`

清單、記帳與筆記都存在瀏覽器的 localStorage，不會上傳到任何伺服器。

## 技術
純 HTML / CSS / JavaScript，不需要編譯。
- Tailwind CSS（Play CDN）、Geist 字體
- Lenis 平滑滾動
- GSAP：SplitText（Hero 逐行浮現）、ScrollTrigger（圖片 pin 放大、卡片滑入）
- Motion：其他元素淡入上滑

## 檔案結構
```
index.html      頁面結構
css/style.css   樣式
js/data.js      行程、培訓、清單、注意事項資料（修正行程只要改這裡）
js/images.js    圖片網址與授權資訊
js/app.js       互動功能（日期選單、清單、記帳、筆記、預算試算）
js/motion.js    動畫
```

## 本機預覽
```
python -m http.server 5500
```
然後開啟 http://localhost:5500
